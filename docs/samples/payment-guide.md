# 결제 서비스 확인 가이드

> 가상 실습 자료입니다. 아래 내용은 실제 운영 지시가 아닙니다.

| 항목 | 값 |
| --- | --- |
| 문서 ID | `payment-guide` |
| 서비스 ID | `payment-service` |
| 담당팀 | 결제팀 (`payment-team`) |
| 직접 의존하는 서비스 | 인증 서비스 |
| 이 서비스에 직접 의존하는 서비스 | 주문 서비스 |

결제 서비스는 가상 결제 요청을 처리합니다. 요청자의 인증 상태를 확인하기 위해 인증 서비스를 사용하며, 주문 서비스에서 결제 요청을 받는다고 가정합니다. 실제 결제 처리나 외부 결제 시스템 연결은 구현하지 않습니다.

## 실습 시나리오

“주문 중 결제 오류가 보일 때 관련 담당팀과 문서는 무엇인가?”라는 질문에 답하기 위해 다음 정보를 모읍니다.

1. `payment-service`의 담당팀이 결제팀인지 확인합니다.
2. 나가는 `DEPENDS_ON` 관계로 인증 서비스를 찾습니다.
3. 인증 서비스 담당팀인 플랫폼팀과 [인증 서비스 확인 가이드](auth-guide.md)를 함께 확인합니다.
4. 들어오는 `DEPENDS_ON` 관계로 주문 서비스를 찾고, [주문 서비스 확인 가이드](order-guide.md)를 확인합니다.

이 실습에서는 “의존하는 서비스”와 “나에게 의존하는 서비스”를 구분하는 것이 핵심입니다. 화살표 방향을 바꾸면 조회의 질문도 바뀝니다.

`payment-guide` 노드는 `DESCRIBES` 관계로 결제 서비스에 연결됩니다. `source`는 `docs/samples/payment-guide.md`입니다.
