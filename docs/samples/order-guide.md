# 주문 서비스 확인 가이드

> 가상 실습 자료입니다. 아래 내용은 실제 운영 지시가 아닙니다.

| 항목 | 값 |
| --- | --- |
| 문서 ID | `order-guide` |
| 서비스 ID | `order-service` |
| 담당팀 | 커머스팀 (`commerce-team`) |
| 직접 의존하는 서비스 | 인증 서비스, 결제 서비스 |

주문 서비스는 가상의 주문 접수를 처리합니다. 요청자의 인증 상태를 확인할 때 인증 서비스를, 결제를 요청할 때 결제 서비스를 사용한다고 가정합니다.

## 실습 시나리오

“주문 과정에서 인증 오류가 보인다”는 질문에 답하기 위해 다음 정보를 모읍니다.

1. 그래프에서 `order-service` 노드를 찾습니다.
2. `OWNED_BY` 관계를 따라가 주문 서비스 담당팀이 커머스팀인지 확인합니다.
3. `DEPENDS_ON` 관계를 따라가 인증 서비스와 결제 서비스를 찾습니다.
4. 인증 서비스 담당팀인 플랫폼팀과 [인증 서비스 확인 가이드](auth-guide.md)를 확인합니다.
5. 결제 과정까지 함께 살펴보려면 [결제 서비스 확인 가이드](payment-guide.md)를 확인합니다.

이 데이터만으로 실제 오류 원인을 확정할 수는 없습니다. 그래프는 조사할 서비스·담당팀·문서를 찾는 데 사용합니다. 주문 서비스가 의존하는 서비스의 장애가 주문 처리 전체에 반드시 장애를 일으킨다는 뜻도 아닙니다.

## 그래프와 원문의 관계

이 파일의 문서 노드는 `order-guide`이며, `DESCRIBES` 관계로 `order-service`에 연결됩니다. 노드의 `source` 속성은 저장소 기준 경로인 `docs/samples/order-guide.md`입니다. 본문 전체를 자동 분석해 관계를 추출하는 기능은 이 기초 실습에 포함되지 않습니다.
