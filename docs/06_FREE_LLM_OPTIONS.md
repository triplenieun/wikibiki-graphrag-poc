# 무료 LLM 선택: 외부 실습은 Ollama, 사내에서는 기존 LiteLLM 연결

조사 기준일: **2026-10-18**. 아래 모델, 무료 제공 범위, 정책은 이 날짜에 확인한 공식 문서를 기준으로 합니다. 반입 시점에는 링크와 실제 계정의 이용 조건을 다시 확인하세요.

이 실습의 외부 개발 환경은 **Ollama로 PC에서 모델을 실행**하는 방식을 사용합니다. 현재 Neo4j에 저장된 문서와 관계를 읽고, 그 근거를 로컬 모델에 전달해 한국어 답변을 생성합니다. 이 로컬 경로에는 외부 LLM 계정이나 API 키가 필요하지 않습니다.

**사내에 이미 로컬 LLM과 LiteLLM이 있다면 그 서버를 재사용하면 됩니다.** LiteLLM은 여러 모델을 공통 HTTP API로 연결하는 게이트웨이이며, 모델 자체가 아닙니다. 프로젝트의 `LLM_PROVIDER=litellm`을 선택하고 사내 주소·모델 별칭·발급받은 키를 설정합니다. 사내에서 Ollama를 추가 설치하거나 아래 모델을 반드시 반입할 필요는 없습니다. [LiteLLM 공식 시작 가이드](https://docs.litellm.ai/docs/proxy/quick_start)

## 1. 여기서 말하는 무료

두 가지를 구분해야 합니다.

- **로컬 모델:** 다운로드한 모델을 자체 장비에서 실행하므로 외부 서비스에 내는 요청당 API 요금이 없습니다. PC·서버·GPU·저장장치·전기·운영 비용은 별도입니다.
- **클라우드 무료 구간:** 제공업체 서버를 무료 한도 내에서 호출합니다. 계정, API 키, 인터넷 연결이 필요하고 질문과 근거 문서가 외부 서버로 전송됩니다. 모델별 한도나 정책이 바뀔 수 있습니다.

`4B`는 약 40억 개 규모의 모델 파라미터를 뜻합니다. 더 큰 수가 모든 업무에서 더 좋은 답변을 보장하지는 않습니다. `Q4_K_M` 같은 표기는 모델 가중치를 적은 비트로 표현하는 **양자화 형식**입니다. 배포 파일 크기와 실행 중 필요한 RAM·VRAM은 서로 다릅니다.

## 2. 검토한 선택지

| 선택지 | 무료 범위와 제한 | 계정·인터넷 | 이번 프로젝트에서의 판단 |
| --- | --- | --- | --- |
| 기존 사내 LLM + LiteLLM | 회사의 운영·할당 정책에 따름. LiteLLM이 추론 비용을 무료로 바꾸는 것은 아님 | 사내 접속 주소·모델 별칭·필요한 경우 발급 키 | **사내 사용의 우선 경로**. 기존 인프라를 그대로 연결 |
| Ollama + `qwen3.5:4b` | 로컬 추론 API 사용료 없음. 장비 성능에 따라 응답 속도 차이 | 공개 모델의 로컬 실행은 키 불필요. 최초 이미지·모델 다운로드 후 내부 실행 가능 | 기본 후보. 로컬 답변과 사내망 이관에 적합 |
| Ollama + `qwen3:1.7b` | 더 작은 로컬 모델. 상세 답변과 근거 준수 품질을 별도 확인 | 위와 같음 | 메모리 부족 또는 CPU 실습에서 비교할 대안 |
| Ollama + `qwen3:4b-instruct-2507-q4_K_M` | 로컬 사용료 없음. 텍스트용 비추론 모델 | 위와 같음 | Qwen3.5 대신 시험할 명시적 버전의 대안 |
| Gemini Developer API 무료 구간 | 일부 모델의 입력·출력이 무료. 요청 수·토큰 수 등의 한도 적용 | Google 프로젝트·API 키 및 외부 접속 필요 | 가상 데이터로 외부에서 비교 가능. 사내망 기본 경로에는 사용하지 않음 |
| GroqCloud Free Plan | 지원 모델별 요청 수·토큰 수 한도 내 무료 | Groq 계정·API 키 및 외부 접속 필요 | 외부에서 성능 비교 가능. 이 저장소에는 어댑터 미구현 |

이 표는 조건 비교이며 응답 품질 벤치마크 순위가 아닙니다. 현재 웹페이지에서 구현한 연결은 **Ollama 직접 연결과 LiteLLM의 OpenAI 호환 API 연결**입니다. Gemini와 Groq의 API 키를 `.env`에 넣어도 해당 회사의 API에 직접 연결되지 않습니다. 사내 LiteLLM에 등록된 별칭이 실제로 어떤 모델 서버로 연결되는지는 사내 운영 설정이 결정합니다.

### 로컬 모델 크기와 라이선스

Ollama 공식 배포 목록 기준 `qwen3.5:4b`는 Linux/Windows에서 사용하는 양자화 배포가 약 **3.3GB**, MLX 배포가 약 **4.0GB**로 표시됩니다. `qwen3:1.7b`는 약 **1.4GB**, `qwen3:4b-instruct-2507-q4_K_M`는 약 **2.5GB**입니다. 내려받는 시점과 플랫폼에 따라 값이 바뀔 수 있습니다. [Qwen3.5 4B 배포 정보](https://ollama.com/library/qwen3.5:4b), [Qwen3 태그 목록](https://registry.ollama.com/library/qwen3/tags)

Qwen 공식 저장소는 위 세 모델을 Apache-2.0으로 배포합니다. 해당 라이선스 조건을 지키면서 상업적 이용이 가능한 모델입니다. 반입 자료에는 정확한 모델 이름과 원본 LICENSE를 함께 보관하세요. Ollama 실행 프로그램의 MIT 라이선스와 모델의 라이선스는 별개입니다. [Qwen3.5-4B LICENSE](https://huggingface.co/Qwen/Qwen3.5-4B/blob/main/LICENSE), [Qwen3-1.7B 모델 카드](https://huggingface.co/Qwen/Qwen3-1.7B), [Qwen3-4B-Instruct-2507 모델 카드](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507), [Ollama LICENSE](https://github.com/ollama/ollama/blob/main/LICENSE)

단순한 `qwen3:4b` 별칭은 조사 시점에 Thinking 계열을 가리킵니다. 비추론 응답을 비교하려면 위 표의 명시적인 `instruct-2507-q4_K_M` 태그를 사용하세요. 긴 추론 출력은 간단한 근거 요약에서 응답 대기 시간을 늘릴 수 있습니다. [공식 Qwen3 태그 목록](https://registry.ollama.com/library/qwen3/tags)

실습용 16GB RAM PC에서도 OS, Neo4j, Docker가 함께 메모리를 사용합니다. 모델 파일이 3.3GB라는 이유만으로 RAM 3.3GB면 충분하다고 계산하지 마세요. 먼저 짧은 질문으로 확인하고, 메모리 부족이나 긴 대기가 발생하면 작은 모델 또는 사내 모델 서버를 선택합니다. 이 프로젝트의 답변 생성 속도는 해당 장비에서 직접 측정해야 합니다.

### 클라우드 무료 구간을 기본으로 사용하지 않는 이유

Gemini 무료 구간은 모델별로 지원 여부가 다르고, RPM(분당 요청), TPM(분당 토큰), RPD(일일 요청) 같은 한도가 적용됩니다. 정확한 현재 한도는 AI Studio의 프로젝트 화면이 기준입니다. API 키가 필요합니다. [공식 가격표](https://ai.google.dev/gemini-api/docs/pricing), [한도 설명](https://ai.google.dev/gemini-api/docs/rate-limits), [API 키 안내](https://ai.google.dev/gemini-api/docs/api-key)

Gemini의 일반적인 무료 서비스 약관은 입력·출력을 제품 개선에 사용할 수 있고 사람이 검토할 수 있다고 설명합니다. 지역 및 결제 상태에 따른 적용 차이가 있으므로 해당 계정의 조건을 확인해야 합니다. 한국의 일반적인 무과금 실습에서는 가상·공개 데이터를 사용하세요. [Gemini 무료 서비스의 데이터 처리 조건](https://ai.google.dev/gemini-api/terms#unpaid-services)

Groq 공식 무료 한도 표의 예로 `openai/gpt-oss-20b`는 조사 시점 **30 RPM, 1,000 RPD, 8,000 TPM, 200,000 TPD**입니다. 조직별 실제 한도는 콘솔에서 확인해야 하며 한도 초과 시 429 응답을 받습니다. [Groq 무료 한도](https://console.groq.com/docs/rate-limits), [계정·API 키 시작하기](https://console.groq.com/docs/quickstart)

Groq는 일반 추론 입력·출력을 기본적으로 보관하지 않지만, 기능상 보관이나 안정성·악용 조사 등의 예외를 설명합니다. 보관하지 않는다는 정책과 외부로 전송하지 않는다는 조건은 서로 다릅니다. 두 클라우드 서비스 모두 사내망에서 사용하려면 외부 호출이 가능한 환경과 회사의 사용 조건이 필요합니다. [Groq 데이터 처리 정책](https://console.groq.com/docs/your-data)

## 3. 모델 실행을 Django와 분리한 이유

```text
브라우저 → Django(Python 3.14) → Neo4j: 근거 조회
                         └──→ Ollama 또는 사내 LiteLLM: 근거로 답변 생성
```

Django는 HTTP로 모델 서버에 요청합니다. Python 가상환경에 PyTorch, Transformers, GPU용 패키지를 추가하지 않아도 됩니다. 모델 실행 환경과 Django 개발 환경을 각각 관리할 수 있고, `.env`로 외부 실습용 Ollama와 사내 LiteLLM 연결을 바꿀 수 있습니다.

Ollama의 로컬 API는 기본적으로 인증 키를 요구하지 않습니다. 제공된 Compose 설정은 PC의 `127.0.0.1:11434`에서만 접속하도록 구성하며, 클라우드 기능은 `OLLAMA_NO_CLOUD=1`로 끕니다. 사내 공용 서버로 연결할 때는 운영팀이 정한 접근 방식으로 주소를 설정하세요. [Ollama API 인증](https://docs.ollama.com/api/authentication), [로컬 실행·클라우드 비활성화](https://docs.ollama.com/faq)

모델을 사내 환경에서 비교할 때는 같은 질문과 같은 검색 근거를 사용하고 다음을 기록하면 됩니다.

| 확인 항목 | 이 실습에서의 예 |
| --- | --- |
| 근거 정확성 | 주문 서비스의 담당팀을 커머스팀이라고 설명하는가? |
| 관계 방향 | 인증 장애의 영향 후보를 역방향으로 찾았는가? |
| 문서 준수 | 운영 문서에 없는 조치나 담당자를 만들어 내지 않는가? |
| 출처 확인 | 답변 옆의 문서와 그래프 근거로 내용을 확인할 수 있는가? |
| 모르는 질문 | 근거에 없는 정보임을 드러내는가? |
| 실행 비용 | 첫 답변·후속 답변 시간, RAM·VRAM 사용량은 얼마인가? |

작은 모델이 문법적으로 자연스러운 답을 내더라도 내용이 맞는지는 별도 문제입니다. 화면에 함께 표시되는 그래프 사실과 문서 원문을 기준으로 판단합니다.
